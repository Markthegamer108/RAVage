04How to play

Getting on

  1. Patch your disc

    Use a Mario Kart Wii disc you own and the WiiWave patcher (wiiwave.py). It rewrites the Nintendo WFC addresses so the game talks to this server.

  2. Connect

    On the Wii, open Mario Kart Wii and choose Nintendo WFC. The patched game finds the server by itself, so there is no DNS or proxy to set up.

  3. Race

    Every ranked race is reported to the league. The weekly, stage and championship tables on this page update every minute.
