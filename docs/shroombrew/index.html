A Wii shop for
homebrew.

Shroombrew looks and behaves like the Wii Shop Channel, but what it sells is homebrew. The points are free, the apps are the Open Shop Channel's catalog, and the website runs the rest.

Open the live siteSource
01Points

Wii Points you make yourself

On the website you press a button and get a card number. It is worth 1000 Wii Points and works once. On the Wii you choose Add Wii Points and type the number in. A new card takes 15 seconds, and each address can only hold a few unused ones, so nobody can flood it.

02Your console

One code ties a Wii to the site

The shop asks the Wii who it is once per launch and keeps only a keyed hash of its identifiers. Settings on the Wii gives a code that works once. Typing it into the website lets the site show your points history, friends and gifts.

03Installing

Straight from the shop

Apps are meant to download through the normal shop install as their own channel. The channel unpacks the app onto the SD card the first time it starts, then launches it. Six apps are too big for that and still use a ZIP.

04Credits

Whose work this is built on

The shop's look comes from wiishopchannel.net by Nathan, used with permission. The apps come from the Open Shop Channel. The server started from WiiSOAP. Shroombrew is free, and if anyone charged you for it you were scammed.
